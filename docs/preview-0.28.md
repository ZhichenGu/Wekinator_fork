# 预览版 0.28

## 本批变化

- 首页三类项目以分区卡片展示；宽屏横排，小屏竖排；分类标题 18 px、空状态 13 px，减少空白并增加真实数量。已有项目保留打开、重命名、删除。
- 语音关键词可选 OpenAI 或科大讯飞。讯飞填写 APPID、APIKey、APISecret，选择中文或英文；对应语音听写（流式版）v2，不兼容其他讯飞服务的凭证。声音事件仍使用支持音频理解的 OpenAI，音量在本机处理。
- 讯飞凭证签名由服务端生成，固定 wss://iat-api.xfyun.cn/v2/iat。麦克风音频转为 16 kHz 单声道 PCM，按 40 ms 分帧。验证按钮只检查签名握手，APPID、语音听写服务权限与额度须实际识别验证。
- 视觉和声音的 API 配置：应用后验证成功自动收起，保留展开箭头；失败保持展开。凭证不持久化。
- 声音事件可导入音频或本地录制，先试听裁切，显式设置为命名参考样例。源文件最多 10 MB、60 秒；送检与参考最长 10 秒。统一转换为 16 kHz 单声道 PCM WAV，10 秒约 313 KB。新录音或上传音频与参考一起送往 OpenAI 比较，属于 API 参考匹配，并未训练本地识别模型。
- 用户显式设置的参考音频保存在项目内，含声音标签；待测录音、API Key 与转写不保存。参考音频会随 JSON 导出，页面有提示。
- 音量映射：输入低高点决定归一化范围，映射到自定义输出最小最大值（可反向），范围外限制到端点。可使用当前电平校准，也可边读取边修改。输出直接发送映射值；停止不发送零值。
- 自定义视觉条件使用完整判断句，默认“杯子是否倒放在桌面上”，附判定依据；物体检测保留物体名语义，不合并入口。

## 验证与限制

- 自动检查共 105 项通过：包含配置白名单、讯飞签名、分帧、重采样、取消、参考片段与待测片段分离、项目往返、中英文组件、计数与其他既有功能回归。
- TypeScript 与生产构建通过。
- 浏览器访问被用户保存的权限设置阻止，实际页面、试听、摄像头和麦克风交互未实测。
- 未使用真实账户密钥请求讯飞或 OpenAI，未进行识别准确性、延迟与费用实测；未连接 Arduino/ESP32。
- 源码保存在本地，尚未推送或部署。

讯飞协议依据：https://www.xfyun.cn/doc/asr/voicedictation/API.html
