# 当前交互与验收

2026-11-13 · 本地源码 0.79。实际代码与测试优先于历史规格。

## 当前使用路径

- 首页创建追踪、视觉或声音项目。追踪提供六种方式，坐标输出不需要训练。未开启摄像头时，学习、坐标与视觉检测的开启按钮均在画框中央。
- P 打开设置；学习项目的空格用于开始/保存录制。表单控件保留原生键盘行为。
- 项目自动保存在当前浏览器/来源，顶部成功状态后才可视为保存完成；换端口、浏览器、网页/桌面不共享项目。MQTT/OSC 的连接草稿仍需保存或应用；Key 与 MQTT 密码不随项目保存。
- 坐标项目按 P 选择输出协议，在居中窗口命名并勾选轴；连接参数可折叠。测试发送使用草稿，运行使用已应用配置；关闭窗口放弃未应用名称与轴，但已保存的连接参数保留。
- 教程按 Serial、MQTT、OSC、案例、排错导航。下载按连接工具、触发、连续数值、坐标分组，并只出现在相关协议教程中。
