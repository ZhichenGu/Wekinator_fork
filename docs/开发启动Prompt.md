# 继续开发当前项目

先读仓库 `AGENTS.md` → `PROJECT_CONTEXT.md` → 当前任务相关源码与测试，以实际代码为准。沿用用户本轮指定的正式目录或预览副本，不重建项目。

完成用户要求范围内的修改与必要验证；可逆的实现细节自行决定，实质改变目标或缺少授权时再集中澄清。用户已说明自行推送 GitHub 时，只准备本地改动。预览合回正式目录、推送、部署与重打桌面包是不同动作，按各自授权执行。

保留现有中英文界面、识别方式与输出协议。教程随真实交互与消息格式更新；下载包与源码同步。项目自动保存和连接参数的应用按钮分别说明。不得把历史规格中的“未实现”或“不使用 OSC”等旧要求当作当前限制。

按用户可观察结果验收。检查受影响入口、返回与错误恢复；持久化变化检查重开，协议变化核对真实发送与接收解析。报告实际环境与限制，不能把脚本、模拟输入或构建通过当作真人、硬件或接收软件实测。

交付说明见 `README.md`、`docs/当前交互与验收.md`；发布规则见 `docs/RELEASING.md`。旧版本规格仅用于追溯。
