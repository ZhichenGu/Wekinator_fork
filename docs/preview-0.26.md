# 预览版 0.26

本批实现此前规划的六个入口，保持已有项目可读。尚未线上部署。

| 分类 | 功能 | 配置与输出 |
| --- | --- | --- |
| 动作追踪 | 区域与停留 | 镜像视频坐标中的百分比矩形；手腕、鼻尖或髋部中心停留达标触发一次；真实移出至少 0.20 秒后可再次触发 |
| 动作追踪 | 动作关系 | 拇指尖与食指尖、上下唇中心或双手腕的相对距离；上方规则比较上下位置，身体模式检查双手高于肩部；稳定确认后触发一次 |
| 视觉识别 | 人数与物体计数 | 填写目标标签与数量阈值；API 返回非负整数，由本地判断数量是否达到阈值，显示数量和 YES/NO |
| 视觉识别 | 自定义视觉条件 | 填写画面条件及可选描述；单张或定时检查，输出 YES/NO |
| 声音识别 | 语音关键词 | OpenAI gpt-transcribe；显式录制 1–10 秒或提前结束，转写后匹配词或短句，输出 YES/NO |
| 声音识别 | 声音事件 | OpenAI gpt-audio-1.5；显式录音后检查目标声音，输出 YES/NO |
| 声音识别 | 音量控制 | 本地麦克风 RMS 0–1（非分贝）；持续输出数值，最多每秒 10 次，无队列 |

各功能复用状态灯、Serial、MQTT。视觉/音频布尔结果首次确认或改变时输出一次；停止、异常和未知不当作 NO。音量停止不发零。区域与关系无需训练。

声音项目可在本地保存、重命名、删除、导出、重新导入。密钥、MQTT 密码、录音、转写与历史结果不写入项目。音频接口使用登录验证、同源检查、固定官方端点、请求体限制、单会话单在途与限流。科大讯飞尚未接入。声音目前不是自动连续付费检测。

## 联调顺序

允许浏览器访问本地预览后，依次检查新建入口、调整设置、保存并刷新、导出导入、切语言与窄屏布局。再用真实摄像头/麦克风验证进入与解除条件、停止和切后台；API 与 Serial/MQTT 最后使用用户选择的账户和设备验证。计数与声音事件均需用有目标和无目标的样例检查误触发。
