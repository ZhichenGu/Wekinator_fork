# 识别增强与工作台更新（0.47）

动态动作匹配可选择原版或实验增强。增强包括按部位计算相对动作特征、裁去前后静止段、综合多个示范的匹配分数。切换算法需要重新训练，原始录制保持不变。手部、面部和身体分别计算特征；姿态分类、连续控制与规则判断保留各自算法。

使用另外录制的独立测试比较漏检、混淆和负例误触发。合成关键点测试只验证计算逻辑，不能代表真人准确率。长停顿和旋转本身属于动作含义时，需比较关闭对应增强项的效果。

面部可选择嘴部、眼睑、眉部或高级全点；密集显示与参与学习的点分开设置。视觉 API 可选择实际送检区域，声音事件支持参考样例与待测音频裁切，音量可用当前输入标定端点。区域停留和动作关系使用选点、设置、运行流程，无需训练。

迁移前实验副本构建及 153 项现有测试通过。浏览器已验证创建、改名、滑条联动与保存、配置折叠和状态灯。摄像头尝试持续停在模型加载，未完成真人录制、识别精度、付费 API 或硬件端到端验收。
