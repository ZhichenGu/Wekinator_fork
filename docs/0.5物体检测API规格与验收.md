# 预览版 0.5：物体检测 · API

2026-11-05。实现位置：`/Users/zhichengu/Documents/GitHub/Wekinator_fork`。本轮仅修改与验证本地代码，没有 Git 提交、推送或线上发布。

## 使用流程

新建项目 → 选择“物体检测 · API” → 进入工作台。

1. 选择平台与视觉模型。OpenAI 提供 gpt-4.1-mini / gpt-4o-mini；DeepSeek 提供 deepseek-flash。接口与当前官方文档核对，账户实际权限仍以平台为准。
2. 输入自己的 Key，点击“应用配置”。“验证 Key”只查询模型访问权限，不发送图片，也不证明图片识别效果已经通过。
3. 填写一个目标标签与可选描述。此工作台没有录制训练、检测框、hover 或 JSONL。
4. 确认截图目的地与个人 API 额度后，可以选择本地图片检测，或开启摄像头检测当前画面、开始自动检测。
5. 选择状态灯、Serial 或 MQTT。NO 可以选择不发送，YES/NO 内容可自定义。MQTT 配置保存后显式连接。
6. 点击“保存项目”保存于当前浏览器，或导出 JSON。最近物体项目和动作学习项目分开保留；刷新、返回首页或退出后 Key 清空，需要再次填写。

## 结果与发送语义

- YES 绿灯：本次送检截图中发现目标；NO 红灯：本次截图未发现目标，并非保证现实中绝对不存在。
- 未检测、请求中、异常或停止均为灰灯，不发送外部结果。请求失败、空白、拒绝、截断、标签不匹配、布尔值为字符串均不当作 NO。
- 内部结果严格解析 `{ "label": "杯子", "present": true }`，对外显示 YES/NO。没有模型自报的概率或相似度阈值。
- 连续确认次数 1–5；满足要求后首次确认结果与 YES/NO 变化各发送一次。相同结果不重复发送。停止或更换设置后重新确认；输出失败不自动补发。
- 自动检测默认在上次请求完成后等待 3.00 秒，可调 1.00–60.00 秒。一次只处理一个请求，不并发积压，不自动重试付费调用。
- 停止、配置修改、返回首页、摄像头断开或页面进入后台会停止检测，忽略迟到结果。后台时也释放摄像头。取消不能保证撤回已抵达平台的请求或费用。
- 画面固定高 360 CSS px，视频等比留黑；最近送检图可展开核对，避免把延迟结果误认为当前画面的结果。

## 凭证与服务端

- 浏览器仅内存保留 Key，Node 请求期间转发；不写磁盘，不记录 Key 或图片，不自动复用其他用户的凭证。
- 受网站密码验证保护的同源 POST：`/api/objects/check` 和 `/api/objects/detect`。开发、Vite preview 与正式 Node 服务均接入。
- 仅固定官方平台域名与白名单模型，禁止任意 URL 代理；禁止跨源请求，校验 JSON、JPEG 及负载大小。每登录会话最多一个在途请求、每分钟最多 30 次；平台请求超时 30 秒。
- OpenAI 使用 Responses API、`store:false` 与严格 JSON Schema；DeepSeek 使用 Chat Completions 图片输入与 JSON 模式。两者返回均由服务端再次校验。
- 不把上游原始错误、请求体或 Key 回显给用户。401、额度/限流、模型错误、超时与结果错误有明确说明。
- 项目保存/导出字段白名单剔除 Key、MQTT 密码、截图及历史结果。配置应用与项目保存是不同操作；项目保存不保存凭证。
- API 图片由所选供应商处理，其数据政策与计费由平台决定。网站提示中不宣称第三方绝不保留数据。

## 实际验证

- 自动化：40 项前端/算法/数据/输出测试 + 10 项 Node 测试，共 50 项通过；TypeScript 与 Vite 构建通过。
- 新增测试覆盖结构化布尔结果、标签一致、非法结构拒绝、首次/变化输出去重、连续确认、项目凭证白名单、接口登录/来源校验、固定平台与请求形状、Key 查询无图片、上游错误脱敏、DeepSeek 截断拒绝、单次在途与超时无重试。
- 浏览器实际操作：创建 API 项目后隐藏录制/训练选项；应用假 Key、验证 Key、选择测试图片；模拟 YES 绿灯、NO 红灯；重复 YES 两次但只有一条输出记录；停止慢请求后没有追加记录。
- 浏览器保存/导出/恢复：3.25 秒保留；实际下载 JSON 不含假 Key、截图或结果。返回最近项目恢复时 Key 为空、同意勾选清空、未检测。
- 窄屏修复：隐藏文件输入框原先造成 408px 横向宽度，已修复。390px 视口下 document 宽度 390，按钮/输入/下拉/链接未见横向越界，预览高 360。桌面截图已目视检查中文与按钮。
- API 流程测试使用独立的本地模拟上游，不请求 OpenAI/DeepSeek、不消耗额度；截图顶部明确标注“模拟，不代表真实 API 识别”。

## 限制与未验证项

没有用户真实 Key，未进行真实平台识别效果、计费或账户权限验证；没有使用用户摄像头、真实 Serial 设备或外部 MQTT Broker。本轮复用已有输出实现，不能把测试状态灯视为设备执行。自动摄像头连续运行及浏览器后台行为需在实际设备进一步确认。

本轮没有发布 Render。用户按既有部署流程上传本轮源码后，仍可用 `npm ci --include=dev && npm run build` / `npm start`；无需新增服务器端统一 API Key 环境变量，每个用户在页面填写自己的 Key。
