# 当前产品与技术规格

适用：本地源码 0.79。线上部署、已发布的桌面包及其验收必须分别核对，源码不是发布证明。[0.1 原规格](archive/product-0.1.md)已归档。

## 产品与流程

Platform 面向摄像头和声音交互实验。检测器使用预训练模型；录制用于本地动作匹配、姿态分类或回归，不重新训练骨骼网络。

| 输入 | 当前方式 |
| --- | --- |
| 手、脸、身体（单目标） | 动态匹配、姿态分类、连续控制、区域停留、动作关系、直接坐标 |
| 视觉 API | 物体有无、人数/物体计数、自定义条件；手动截图、导图、有限次数自动检查 |
| 声音 | 关键词、声音事件、音量控制；前两者使用自己的 API，音量在本机计算 RMS |

学习先录制、训练、运行；区域与动作关系直接设规则；坐标直接选点输出。独立测试不参与训练、不向外发消息。P 打开设置，空格开始/保存录制、Esc 取消，表单保留原生键盘行为。

项目在当前浏览器/来源自动保存，顶部成功状态才表示写入完成；导出用于迁移和备份。MQTT 保存配置、OSC 应用目标仍需显式操作。账号不提供云端项目同步。API Key、MQTT 密码不随项目保存；显式设置的参考音频可保存并导出。

## 输出与协议

| 类型 | Serial / MQTT | OSC |
| --- | --- | --- |
| 触发、YES/NO | 配置的文本；Serial 支持结束符 | String、int32 或 Float |
| 连续控制、音量 | 单个数值，支持 {value} 模板 | 单个 Float |
| 新坐标项目 | JSON values 命名轴，例如 index_tip_x | 基础地址/点名称/轴，每轴一个 Float |
| 旧 0.77 坐标项目 | points 数组 | 基础地址/点编号，XY/XYZ 向量 |

旧坐标格式在应用命名设置前保留。坐标最多四点，XY 与镜像预览一致且范围 0–1；Z 是相对深度。选中点丢失时整帧暂停，恢复从当前位置继续；停止不会发零。接收端按本机到达时间做超时。

Web Serial 使用支持的桌面浏览器和真实可通信的串口链路；两个软件不能双占同一 USB 口。网页 MQTT 使用 WebSocket，HTTPS 使用 WSS。网页 OSC 需要浏览器电脑上的新版桥接，桌面版内置；接收端 IP、UDP 端口与地址须匹配。具体格式见[坐标接收说明](../public/examples/coordinates/README.md)。

## 技术与边界

React、TypeScript、Vite、Node；MediaPipe JS/WASM 版本保持同步，模型文件随源码/桌面包提供。检测优先 Worker，兼容回退主线程。视觉/声音 API 走同源服务端固定上游，不是任意代理；付费识别需用户同意，单在途、不自动重试。

界面沿用白、浅灰、淡蓝，状态同时有文字。摄像头启动入口在画框中央，视频和骨骼保持相同有效矩形与镜像。学习工作台大画面向上移出约三分之一时显示小预览，恢复四分之三收起；坐标页当前没有浮动小预览。

未实现双手融合、多人识别、自训练 YOLO、语义分割、云端项目同步。分数不是概率，算法增强不保证所有动作更准确。构建、模拟与真实软硬件验收不互相替代。

用 `npm ci`、`npm run dev` 启动；构建用 `npm run build`，正式服务用 `npm start`；纯静态托管不能替代账号与 API 服务。测试入口与实际结果见[当前验收](当前交互与验收.md)，源码导航见 [PROJECT_CONTEXT](../PROJECT_CONTEXT.md)，发布与安装包见[发布说明](RELEASING.md)。
