# 0.78 坐标输出预览验收

## 操作路径

新建项目 → 动作追踪 → 手／脸／身体 → 直接输出坐标。默认手为食指尖 8、脸为鼻尖 1、身体为左手腕 15。可通过画面或下拉框选点，最多四个。按 P 设置 XY／XYZ、频率、平滑和连接。用“测试发送”核对连接，再开摄像头与“开始输出”。

## 本次实现取舍

- 默认只选一个点，使用轻度平滑和 10 Hz。可以增加到四个点，控制单帧 JSON 长度在现有 Serial/MQTT 512 字符限制内。
- XY 与镜像预览相同，固定在 0–1；Z 保留模型相对深度。深度参考位置因检测器而异。
- 频率为上限，取决于检测与连接速度。只有一个在途输出，忙时跳过帧，避免积压旧坐标。
- 任一选中点不可用时整帧暂停；恢复后重置平滑，从当前值继续。停止与丢失不会发送零值，接收端需按自己的到达时间做超时。
- Serial 每行一帧 JSON，MQTT 每条消息一帧 JSON。OSC 每个点一条消息，基础地址后自动追加点编号。多点 OSC 的 UDP 包按点独立到达。

## 0.78 命名窗口

P → 输出方式 → Serial／OSC／MQTT 打开居中窗口。只勾选需要的轴，并为各点命名；至少一个轴，名称不重复。OSC 自动生成基础地址／点名称／轴；Serial 与 MQTT 按 values 中的 点名称_轴 字段读取。关闭、Esc 与窗口外点击取消未应用的命名草稿。连接参数单独展开并应用。旧项目应用前保留原格式。

逐轴实测已用页面测试发送核对两个点的 X/Z 独立地址，未出现 Y。已检查重名保护、Esc 取消、刷新保留、中英文窗口，以及 1280px/390px 布局边界。

### 摄像头入口与兼容修复

- 原有手、脸、身体追踪、坐标输出和视觉检测共用画框中央的摄像头开启入口；加载时禁用，成功后移除占位。下方不再重复开启按钮，保留运行、停止等操作。
- 坐标视频改为画框内绝对定位，按来源宽高比显示，并限制视口高度，避免未开启时被视频固有尺寸撑高。
- 坐标检测补齐 Worker 初始化失败或超时后主线程兼容回退；停止、离开和后台切换释放线程、模型与摄像头。停止后才完成的图片帧会关闭且不发坐标。
- 浏览器使用纯色合成画面，手、脸、身体三种真实 MediaPipe 模型均加载并完成检测（兼容模式，零个目标符合测试画面）；未使用真人摄像头，不能据此判断真人识别准确率。
- 浏览器查看手、脸、身体坐标页、原动态追踪与物体检测的中央入口；坐标页另检 390px 窄屏，按钮在框内，无横向溢出。
- 141 项前端与算法测试、30 项服务端测试通过，构建通过。仅修改预览副本，未合回正式目录。
