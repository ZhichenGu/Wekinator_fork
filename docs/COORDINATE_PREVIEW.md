# 0.77 坐标输出预览验收

## 操作路径

新建项目 → 动作追踪 → 手／脸／身体 → 直接输出坐标。默认手为食指尖 8、脸为鼻尖 1、身体为左手腕 15。可通过画面或下拉框选点，最多四个。按 P 设置 XY／XYZ、频率、平滑和连接。用“测试发送”核对连接，再开摄像头与“开始输出”。

## 本次实现取舍

- 默认只选一个点，使用轻度平滑和 10 Hz。可以增加到四个点，控制单帧 JSON 长度在现有 Serial/MQTT 512 字符限制内。
- XY 与镜像预览相同，固定在 0–1；Z 保留模型相对深度。深度参考位置因检测器而异。
- 频率为上限，取决于检测与连接速度。只有一个在途输出，忙时跳过帧，避免积压旧坐标。
- 任一选中点不可用时整帧暂停；恢复后重置平滑，从当前值继续。停止与丢失不会发送零值，接收端需按自己的到达时间做超时。
- Serial 每行一帧 JSON，MQTT 每条消息一帧 JSON。OSC 每个点一条消息，基础地址后自动追加点编号。多点 OSC 的 UDP 包按点独立到达。
